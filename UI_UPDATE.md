# SecureVault UI refresh

This version keeps the same functionality but changes the visual system so SecureVault feels clearly separate from Matchly.

- Dark security sidebar on desktop
- Warm ivory workspace instead of cool purple/gray dashboard styling
- Forest-green accent instead of violet
- Editorial serif display headings paired with clean sans-serif UI text
- Flatter credential rows and fewer floating cards
- Compact security summary strip
- Centered editorial authentication experience instead of a split-screen hero
- Mobile layout preserved with a compact top bar

Run the app the same way as before:

```bash
npm run dev
```
